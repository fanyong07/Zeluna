# Code of Conduct

Zeluna contributors are expected to be respectful, specific, and safety-minded.
Harassment, discrimination, threats, doxxing, credential sharing, malicious
provider probing, and attempts to bypass access controls are not acceptable.

Report conduct concerns privately to the repository maintainers rather than
publishing personal information in an issue. Maintainers may remove content,
limit participation, or reject contributions that put users, providers, or the
project at risk.
