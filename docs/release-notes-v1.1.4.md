# Zeluna v1.1.4 候选交付说明

## 背景与目标

v1.1.3 候选验收修复了文件选择器返回 Windows 盘符路径时无法播放的问题；合并前审查又发现，播放引擎内部仍会把 UNC 网络共享地址误写为本地路径。本候选补齐原生播放边界，保留已生成的旧候选，不覆盖或复用其版本与证据。

## 范围与实现

- 继承 v1.1.3 的两个文件选择入口规范化，以及无启动图、原生全屏和窗口状态恢复。
- 仅在 Windows 原生播放入口把带共享主机的 file URI 转回 UNC 路径，防止引擎内部解析时丢失共享服务器。
- 保留解析器和 Web 使用的 file URI，不改变普通盘符、POSIX 路径、网络媒体地址及请求头。
- 不升级依赖、不改包名、签名、权限、用户数据与后端；不启用任何网络共享服务。
- 版本递增为 1.1.4+58；v1.1.3 只作为被替代的本地候选，未公开发布。

## 验收标准

1. 回归测试贯穿文件选择路径、应用规范化与实际播放引擎的 URI 规范化，覆盖共享主机名、IP、中文、空格、井号、百分号及已有 file URI。
2. 原始失败用例先红后绿，Flutter 格式、分析、全量测试与精确提交的 Quality Gates 通过；跳过项单列。
3. 使用本地无敏感测试视频验收当前 Windows 构建的启动、播放及普通/最大化窗口的全屏进退。
4. 候选包、构建证据、门禁、manifest、版本和 Git SHA 一致，原启动图片不进入包体。
5. 四材料沿用 engineering-goal-progress.md 的历史实读记录：total=4、read=4、skipped=0，不声称本轮重新阅读。

## 限制、回滚与待确认

- UNC 测试验证到引擎输入边界，不表示已连接实际网络共享、验证账号权限或音频输出。
- 正式 Android 仍需要受保护的生产签名、原升级身份确认及真实设备安装/覆盖升级验收；不以 Debug 签名或 Windows-only 包冒充整套正式发布。
- 弹弹play真实服务端凭据及外部片源联调仍单独验收；不以模拟测试替代。
- 本轮无后端差异，不重复重启或部署生产服务。回退使用上一份不可变产物，不清空用户数据。
