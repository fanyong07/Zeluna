# 字幕增强：实现与验收交接

> 需求已追加「服务器内置、可选 Google Drive」。服务器当前实现与未完成边界以 `subtitle-server-library.md` 为准；本文保留上一阶段本地能力与验证记录。本文中的短期缓存限制仅适用于外部在线 provider，不限制已审核的内置库。

## 背景与目标

片源多数已有中文（可能烧录在画面中），不能为了补日语或英语而替换主字幕轨。本功能将原文字幕作为独立 Flutter 文本层显示，与播放器已有字幕并存；按应用内作品与分集绑定，不扫描视频目录。

## 当前范围

- 播放器顶部「字幕」入口，桌面与手机使用现有功能面板。
- 默认不启用外挂；根据作品语言预选日语／英语／简中。国语作品默认保持原样。
- 导入 SRT、ASS/SSA、VTT；单文件绑定当前集，多文件先核对分集再保存，未指定分集跳过。支持 UTF-8（含 BOM）和带 BOM 的 UTF-16；其他编码明确提示先转 UTF-8。
- 文件选择最多 40 个、每个不超过 5 MB、单次总量不超过 20 MB。不读取压缩包、图片字幕，不做翻译、识别或 OCR。
- 上／下方显示、字号、边距、提前／延后 0.5 秒及重置；偏移正数表示延后，记忆范围是「分集＋线路 ID＋文件内容哈希」。
- 「片源已有双语」只隐藏外挂，记住当前分集和线路；不会关闭、选择或替换播放器的原字幕轨。
- 原文位置使用视频时间，暂停、跳转和倍速不另起计时器。弹幕区域避开字幕条带。
- 独立 Hive 字幕缓存按账号隔离，不进入云端同步；清除有确认步骤，删除账号也会清理字幕，旧账号写入句柄不能恢复被删的数据。
- 本地缓存最多 100 个文件文档，文档累计约 20 MB；淘汰时移除绑定和来源索引。设置等索引有条数上限。内容哈希相同但语言或文件名不同的文件各自保存元数据。

## 在线来源：明确的未启用边界

当前**没有启用真实在线字幕提供方**，不是所有作品都能自动找字幕。

Jimaku 访问政策核验结果和官方源码证据见 `subtitle-source-policy.md`。当前代码固定保持政策关闭，不提供强制抓取环境开关；英文暂没有接入免凭据来源。动漫花园、BT、整部视频提取、全站扫描均不在范围内。

已实现的是来源协议、保守匹配和受控获取基础设施：

- `POST /api/v3/subtitles/search`：传作品／分集稳定标识、标题别名、年份、类型、可选季集元数据和目标语言。没有视频 URL、Cookie、账号令牌字段。
- `GET /api/v3/subtitles/{candidate_id}/content`：只接受服务端短期登记的随机候选 ID，不是任意 URL 代理。
- `found`、`not_found`、`provider_unavailable`、`manual_required` 分开处理。候选有依据和 `auto_match`；`timing_verified` 始终为 false。
- 当前日语返回受限状态；英文／简中返回需要导入。客户端对旧服务 404/405 给出兼容提示，手动导入不依赖服务端。
- 后续经许可接入来源时，必须审核域名白名单与访问规则；每次跳转重新进行公开地址校验，限制体积、超时与缓存，不带用户凭据，不绕过 403／验证码。
- 服务端候选最多 100 个、有效期 10 分钟、内容缓存约 20 MB，只在内存中短期保留，不建设镜像。

## 关键实现约束

1. 原有 `subtitle_controller.dart` 保留。补充控制器只管理自己的文档与状态；Windows 原生字幕 API 和 Web `TextTrack` 不由本功能修改。
2. 切集、换线、切账号、退出时增加 generation／epoch；下载和导入异步完成时重新检查，旧结果不能更新当前画面。
3. 稳定身份使用已有 `identityKey`。`seasonNumber`／`seasonEpisodeNumber` 是可空的附加信息，不改集号、不重编 ID，旧 JSON 无须迁移。
4. 批量匹配仅提供建议；缺失季号不默认第一季，特别篇和歧义需手动指定。远程只有作品与分集身份充分明确且唯一时才能自动加载。
5. 已确认来源可供后续集受控查找；本集文件已缓存时无需重复下载。仅保留原文来源，找不到或受限不影响视频播放。
6. ASS 仅提取对白、时码与换行，不完整复现字体／特效／绘图；混合双语文件保留原文内容，不用字符过滤强行提取某种语言。建议导入纯原文字幕，避免重复中文。
7. 烧录字幕不能自动识别，用户需自行标记已有双语。不同剪辑版本的逐段漂移不能靠单个偏移完全修正，需要用户提供匹配版本或外部调时。

## 验收命令与证据边界

从仓库根目录执行：

```powershell
flutter analyze --no-pub
flutter test --no-pub
server/.venv/Scripts/python.exe -m pytest server/tests -q
flutter test integration_test/player_subtitles_integration_test.dart -d windows --no-pub
flutter build web --debug --no-pub
```

- 新单元／组件测试覆盖解析、编码与体积拒绝、分集建议、切换失效、语言和账号隔离、缓存持久化、旧服务器回退、导入确认、窄屏／大字体和弹幕避让。
- Windows 集成测试只使用生成的本地 AVI、隔离账号与临时 Hive；真实解码，验证中文主轨、外挂原文、拖动、暂停、倍速、已有双语切换、系统全屏切换和实际面板入口。没有外网片源，也不读取用户账号目录。
- Web 的 `test/web_subtitle_playback_test.dart` 只在 browser 平台运行，用生成的 H.264 数据和真实 video/TextTrack，不依赖外部站点。
- 本机 Windows Flutter 的浏览器测试服务出现 CanvasKit 路由 404（静态检查发现路径分隔符兼容风险），导致 `/canvaskit/` 404、测试卡在加载。这属于测试服务问题，不要修改全局 SDK。可使用下面的独立浏览器冒烟入口验证同一播放组件：

```powershell
flutter build web --debug --no-pub -t tool/subtitle_web_smoke.dart --output build/subtitle-web-qa
python -m http.server 5179 --bind 127.0.0.1 --directory build/subtitle-web-qa
```

浏览器访问本机端口，等待标题 `SUBTITLE_WEB_QA_PASS`。此入口只使用内存字幕缓存，不接触用户账号；检查真实解码、保留中文轨、视频时间、跳转、暂停、倍速、双语开关和校时。它不是完整线上页面、网络视频或真机验证。

## 尚需人工或设备验收

- Android 真机／模拟器的文件选择、横竖屏、全屏与系统字体。本次环境没有 Android 设备，不能用组件测试替代真机结论。
- 真实用户片源与不同来源字幕的同步精度；测试视频不能证明所有版本完全同步。
- 未来经许可接入来源时，另行补齐真实候选下载、来源授权、失败保护与服务部署后的端到端验收。

本功能代码没有部署、发布、修改版本或上传字幕；生产后端未被更改。

## 本轮验证记录

- Flutter 静态分析无问题；全量测试 910 项通过，26 项按条件跳过。
- 后端全量 742 tests、233 subtests 通过；保留一条现有 TestClient 依赖弃用提示。
- Web 主应用 debug 编译成功，独立浏览器冒烟实际获得 `SUBTITLE_WEB_QA_PASS`；桌面及 430px 视口截图均可同时看到原中文与外挂英文，浏览器控制台没有 error。
- Web 实测修复了 load() 把初始倍速重置为 1 的已有问题：同时设置 defaultPlaybackRate 和 playbackRate；真实浏览器确认 1.5 倍速保持。
- 浏览器 flutter test 服务本轮无法装载 CanvasKit，因此不将该命令报告为通过；改由编译后的真实 Web 组件冒烟覆盖播放场景。
- 组件截图覆盖 1280×720、430×900、568×320；另有 220px 面板／1.6 倍字号溢出断言。
- Windows 原生集成最终通过，包含真实系统全屏进入／退出、外挂继续显示、中文主轨保持及恢复窗口后打开字幕面板。
