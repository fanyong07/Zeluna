# Zeluna 内置字幕服务器：来源决策与授权证据

核验日期：2026-09-17（Asia/Hong_Kong；本机时间）。状态：有界来源调研完成；不是来源接入或上线验收。

## 1. 结论与立即执行的决策

**本轮核验的 4 个来源中，没有一个已证明同时满足「不新增账号或密钥、允许自动下载、允许长期集中存储、允许向 Zeluna 用户再分发、大范围日语/英语作品覆盖」。当前可立即启用的已授权公共字幕入库来源为 0。** 这是本次证据下的产品准入结论，不是声称全球不存在其他合法来源。

建议父任务继续交付服务器持久库和全站覆盖统计，但将它们明确区分为「基础设施已就绪」与「真实、已授权字幕内容已就绪」。不能用空库、示例字幕、目录命中或研究语料的文件数宣称覆盖全部作品。

## 2. 背景、目标与范围

- 背景：用户希望 Zeluna 内置字幕服务器主动提供尽可能广泛的日语/英语字幕，而不是要求用户逐个导入或列出作品。
- 目标：为自动来源建立可执行准入决策，分别核验访问能力、站点自动化规则、内容保存/再分发权利和覆盖事实。
- 范围：只研究上述 4 类来源，不全站下载，不登录、不注册、不申请 Key、不购买套餐、不联系站方、不绕过 robots、验证码或限流。
- 不做：服务器库实现、客户端改动、部署、全站扫描、Google/Drive 规则研究及存储接入。父任务负责持久字幕库、覆盖统计及新增的 Drive 分工。
- 即使随后改用用户已有的 5 TB 云空间，也必须沿用同一内容授权门槛；增加存储空间不是字幕复制及分发权利的替代品。这里不对 Google 的容量、条款或接入能力作核验结论。

## 3. 逐源证据与边界

### 3.1 Jimaku：日语重点候选，但匿名网页采集明确受阻

- 通过指定本地 You MCP 的 `you_contents` 实读官方 robots，返回 `cached=false`。普通客户端规则是 `User-agent: *`、`Disallow: /`；具名搜索引擎例外不是 Zeluna 的许可，且文件下载及 bulk 路径仍列为禁止。[J1]
- 官方仓库 README 将项目描述为承载动画及其他日语内容的字幕站，源码标示 AGPL-v3。该软件许可不能扩大为用户上传字幕、原剧台词或翻译的内容许可。[J2]
- 既有项目研究记录网页路由在代码层面接受匿名访问，并记录 API 需凭据的路线。本轮重新核验了 robots，但没有重新验证 API 鉴权，也没有将历史固定提交当作当前线上实现。[J3]
- README 中存在迁移 Kitsunekko 的抓取工具说明；这是项目代码能力，不是 Jimaku/Kitsunekko 对 Zeluna 授予的抓取或再分发权利，不能照跑。[J2]
- 覆盖限制：站点日语定位不能推出每部番剧、每季、每集均有字幕，也不能保证与当前视频版本同步；未计算真实覆盖率。
- 必要授权：站方允许实际客户端、端点及访问频率；明确许可的作品/语言/文件范围；内容权利人或有权授权方允许服务器长期保存并向应用用户提供副本。若以 API 获取，仍需核验实际 API 条款与凭据要求。

### 3.2 Kitsunekko：日英动画目录不等于允许镜像

- `you_contents` 实读官方 robots，返回 `cached=false`，内容为 `User-agent: *`、`Disallow: /`。[K1]
- 官方域名的搜索索引展示首页定位及日语、英语字幕分类；这是来源定位证据，不是当日逐文件可下载或有权镜像的证据。发现 robots 禁止后，没有继续请求目录、作品页或字幕文件。[K2]
- 搜索出现第三方全量下载器及镜像。本轮没有采用它们；第三方程序的 GPL/MIT 等代码许可不能证明被下载字幕的许可，也不通过镜像规避原站限制。
- 未取得官方自动采集协议、集中永久存储条款、再分发许可或可用性承诺；应记为「授权未确认且自动访问被阻止」，而不是「免费可用」或「已找到合法开放库」。
- 必要授权：与 Jimaku 相同，须分别解决自动访问许可、具体字幕权利及应用分发用途。不能只向镜像维护者获得下载同意就认定权利链完备。

### 3.3 OpenSubtitles：优先协议候选，不是免 Key 的公共镜像源

- 官方 Getting started 文档的 You 搜索索引明确区分：应用/服务的静态 `Api-Key`，以及用户的 JWT。应用使用自己的 Key，而不是要求每个用户申请开发者 Key。[O1]
- 该官方索引内容描述应用自身可做有限免用户登录下载，并要求希望完全不提示 OpenSubtitles 账号的项目联系站方。它也明确反对把开发者用户名/密码硬编码进公开应用。[O1]
- **不把索引中的每日下载数字当作当前已验证配额**：`you_contents` 对 Getting started 只取回 JavaScript 外壳，`web.run` 打开同页失败。账号/应用实际额度、计费、限流、缓存时长和合同条件均需后续核验；本轮未调用下载 API。[O1]
- 官方 2024-08-26 服务说明支持新 REST API、应用配额区分及商业项目流量，并说明数据库由用户贡献的多语言字幕组成。该历史说明是接口定位证据，不是 2026 年的额度承诺，也没有在已取得内容中提供 Zeluna 集中长期镜像/再分发的许可。[O2]
- 对长期存储的判断是「未获证实，生产禁用」，**不是断言官方所有存储或所有商业使用均被禁止**。API 接入资格、VIP 下载额度、原字幕权利是不同事项。
- 必要协议：明确服务端聚合访问及下载主体；是否允许用户不登录；是否可以长期留存原文件、格式转换件与多副本；是否可向应用用户直接提供；商业使用/地域/署名/删除义务；带宽与请求额度；第三方字幕权利的授权或保证范围。
- 后续若只获按需、有限缓存许可，应按协议交付按需服务，**不能冒充用户要求的持久全量库**。若拿不到持久分发权，应明确该路线无法满足完整目标。

### 3.4 OPUS / OpenSubtitles：公开研究语料不是自动获得播放分发权

- OPUS 的 OpenSubtitles v2024 官方说明报告 93 种语言、3,377 个双语组合、7,707,669 个文件，并要求来源链接及论文引用。这些是版本化语料统计，不是作品数、集数、当前实时规模或 Zeluna 覆盖率。[P1]
- OPUS 当前公开说明强调自己不拥有所提取的原始文本，提供其认为可再分发的文件，并设有通知下架机制。OpenSubtitles 条目在本轮所得内容中没有给出能直接覆盖 Zeluna 长期字幕服务的明确 CC 等内容授权。[P2]
- 语料公开可取、要求学术引用、OPUS 自身提供下载，均不足以推导任意下游应用具有相同权利。不能套用 OPUS 其他子语料的 CC0、CC-BY 或非商业许可到 OpenSubtitles。
- 语料使用清理、句子对齐等处理，提供面向 NLP 的数据格式。本轮未下载样本核验时间码、完整字幕样式、作品/季/集映射及版本同步；**不声称全部时间码已丢失，也不声称可直接转换成可播放字幕**。[P1]
- 本轮未形成日语/英语可用文件数及对 Zeluna 的逐集覆盖证据。英语和日语是目标筛选条件，不是本轮已证明的实际覆盖结果。
- 后续取得官方 robots 后，确认其限制 `/legacy`、若干 `/opus/` 归档模式、`/opusapi`、`/downloads` 等路径；随即停止相关路径内容访问。此次 legacy 说明页提取早于 robots 核验，不能把提取成功写成合规自动接入的证据，也不能复用此顺序做生产抓取。[P3]
- 如将来选择某个明确许可的开放字幕子集，应逐项核验许可涵盖原文/翻译、再分发及目标用途，随后才允许有限样本验证。即便少数开放作品满足条件，也不等于商业动画全目录覆盖。

## 4. 给父任务的接口决策与验收条件（不实现）

### 4.1 来源开启门槛

以下全部满足才可让来源向持久库写入并对用户提供：

1. 自动访问被允许：记录 robots/专用 API 条款/站方书面授权及适用范围；不把具名机器人规则套给自己。
2. 权利链足够明确：分别记录自动获取、长期保存、转换、备份、多用户分发、商业用途等允许或禁止项；来源有权限授权这些内容，不能只记“公开下载”。
3. 授权证据可追踪：来源、文档版本、核验时间、有效期、作品/语言范围、署名及删除条件。过期或范围不明时保持关闭。
4. 有界实测通过：只选少量已授权字幕验证下载、大小/格式安全、作品季集匹配、语言识别与时间同步；不要求用户先列作品，也不以全站下载代替样本验收。
5. 不绕限制：遇登录、验证码、403/429、robots 禁止或条款冲突即停止；不换 UA 冒充搜索引擎，不轮换账号/IP，不借镜像消除权利门槛。

本轮建议 4 个来源均保持禁用或待协议状态；不能仅靠一个无授权证据的配置开关启用。

### 4.2 覆盖统计必须表达真实状态

这是验收口径，不要求本调研重写父任务的数据结构：

- **目录规模**：Zeluna 当前目录的作品/季/集总数，标明统计时点；仅由父任务的真实目录确定。
- **候选命中**：发现可能对应的来源记录，不计入已覆盖。
- **已授权入库**：拥有许可且实际保存、可读取的字幕文件，按真实作品/季/集及语言去重。
- **可播放覆盖**：在已授权入库基础上，具备可信匹配与有效时间轴；质量或同步未知单独标记。
- **未覆盖原因**：未检索、无候选、自动访问受限、等待授权、缺凭据、匹配不明、下载失败或格式异常。不能全部显示“没有字幕”。
- “尽量覆盖所有作品”是目标，不是承诺。禁止把 OPUS 文件量、站点条目数、多语言重复字幕、测试样例或未授权缓存计为全站覆盖。

### 4.3 建议推进顺序

1. 父任务完成与来源解耦的持久库和覆盖统计，允许真实内容为空，界面诚实显示“来源授权待完成”。
2. 将 OpenSubtitles 作为服务级授权谈判的首选；Jimaku 作为日语补充的许可谈判候选。此优先级是基于官方接口与内容定位的工程建议，不是已获授权结论。[O1,O2,J2]
3. 用户确认账号/付费/外部联系后，再申请或联系；本轮不擅自执行。
4. 协议明确后才做有限真实字幕试点，再评估覆盖与存储。若权限不足，保持禁用并反馈差距，不用云盘扩容来掩盖内容缺口。

## 5. 方法、实际执行与证据强度

- 按 research skill 的“第一方来源、单一 Markdown 交接”要求执行。当前工具集没有可用的研究子代理接口，因此没有虚称启动子代理：采用 Python MCP stdio 客户端按 4 个来源分支进行有界并行检索，单轮最多 2 个来源请求在途；未另建用户任务。
- 使用用户指定的 `C:\Users\h1175\.venvs\you-chrome-research\Scripts\python.exe -m you_chrome_research.secure_launcher --data-dir C:\Users\h1175\.claude\you-chrome-research`。每个 MCP 会话先初始化、调用 `health`，再调用 `you_search` / `you_contents`。
- `health` 确认 API 已配置；只打印允许的状态字段，不读取或打印凭据值，不持久化凭据。客户端脚本以内存/stdin 执行，未新增脚本或原始结果文件。
- 有界执行记录：7 次 health；12 次 you_search；11 次 you_contents（部分为多个明确 URL 的批量说明页请求）。没有递归遍历、字幕下载、全站镜像或账号操作。
- 已按要求另用 `web.run` 核验主要官方来源。成功获取 OPUS 当代站点及其免责声明；OpenSubtitles Getting started 打开失败，部分搜索无结果。**不能将这些失败写成双来源验证成功。** Jimaku/Kitsunekko 实时 robots 证据来自 You MCP。
- `cached=false` 是 You MCP 返回状态，不保证目标站内容绝对最新；搜索命中属于官方页面的索引证据，不能等同于当日成功直读。
- 失败/限制：Jimaku 若干猜测 API 源码路径为 404，未作为有效证据；OpenSubtitles 猜测 terms 路径为 404，Stoplight 正文抓取仅得 JS 外壳；OPUS 一个语言对路径为 404。没有通过登录、禁用防护或改变身份重试。
- 未调用下载端点，未取得真实作品字幕，未运行字幕播放、服务器或应用测试。本轮文档检查不等于产品功能验证。
