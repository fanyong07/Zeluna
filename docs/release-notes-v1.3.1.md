# Zeluna v1.3.1

Flutter version: `1.3.1+87`。本版集中修复搜索联想点击、完整查线收尾，并整理线路布局与连接/探测等待。

## 更新内容

- 修复搜索框下方联想词条点击后无响应：输入框与下拉浮层使用同一点击区域分组，避免鼠标按下时提前失焦、销毁菜单。首页、分类页与搜索结果页均可直接打开对应作品详情，不会额外重搜或重复跳转。
- 修复搜索历史点击和删除受同一焦点问题影响的行为；保留键盘搜索、搜索箭头和真正点击外部时收起菜单。
- 移除手动“本机重查（本集）”按钮及确认弹窗，保留正常自动章节解析、媒体验证、完整 URL 查看/复制和诊断。
- 线路卡片统一整行宽度、左右边距和编号栏，选中/hover 不再一大一小；延迟、大小、分辨率、格式按响应式等宽列对齐，兼容窄屏与大字体。继续如实显示未知值，不填造媒体数据。
- 系统 DNS 结果加入短时缓存及同主机并发解析合并，减少重复解析等待；每次请求仍校验所有地址、保持 HTTPS SNI 和证书验证。不是 DoH，不承诺视频 CDN 带宽提升。
- 后台候选验证保持四个并发槽，为每个候选增加 12 秒预算并取消其实际请求，超时/异常不阻塞后续候选；保留真实线路与失败状态，不把待解析地址冒充可播直链。
- 修复完整查线进度一直转圈：规则流正常结束时不再错误取消调用方共享任务，确保合并器和页面收到最终完成状态。
