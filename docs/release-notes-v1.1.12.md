# Zeluna v1.1.12 内部同步交付

## 版本与范围

统一版本 `1.1.12+66`，对外文件名使用 `v1.1.12`。Android APK 为 Release 模式、沿用旧安装的兼容签名；不是生产签名身份，不用于公开正式发布。Windows ZIP 包含完整运行目录及 Zeluna.exe，不交付孤立EXE。

2026-09-10用户明确要求执行此前说明的同步打包：允许提交、推送当前修改，通过精确HEAD的Quality Gates后使用兼容签名生成内部双端包。不部署服务器，不创建公开GitHub Release，不改写已发布产物。

## 内容

- Android横屏和Windows复用单行播放器控制栏；弹幕输入位于控制栏中间，紧凑横屏缩小图标、文字和输入框，保留可点击区域。
- 交互菜单和输入焦点期间暂停控制栏自动隐藏；输入文字不触发播放快捷键。
- 修复早期原生进度事件被过滤后未完成首帧状态的遗漏；原生续播定位挂起时释放恢复阻塞。
- 弹幕HTTP暂时失败和明确标记的HTTP 200部分降级可在8秒总预算内有限重试；按来源保留同集旧弹幕，换集拒绝过期结果。
- 服务端增加安全错误分类；授权失败和限流不会被盲目重试。服务端改动未部署，新错误字段的线上生效依赖后续独立部署授权。
- Android原生单测进入CI；Android真实弹幕验证改用显式安装后连接现有应用，禁止测试框架自动卸载正常应用。

## 验收与使用

APK与Windows完整ZIP必须来自同一干净提交，版本、build与manifest一致。打包脚本拒绝覆盖旧文件。Android安装只允许核对签名后的覆盖安装；失败停止，不卸载回退。正常入口必须为lib/main.dart，不能交付集成测试入口。

生产签名、服务器部署、公开发布及Android物理ARM手机验收仍是独立边界。保留旧版本与回退材料，不清理用户数据。
