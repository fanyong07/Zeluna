# Zeluna v1.1.14 独立影视范围修复与全线路验收

## 背景与目标
用户要求原站有电影或电视剧时纳入对应板块，不再因为适配器位于动漫目录就跳过。继续验证全部线路，完成后提交合并 main、同步打包 Android/Windows 并上线服务器。

## 版本与范围
统一版本 `1.1.14+68`。双端从同一精确 Git HEAD 构建；不复用或覆盖旧版本。Android 沿用已获准的内部兼容签名，用于侧载覆盖安装，不是生产/商店签名，本轮不创建公开 APK Release。Windows ZIP 包含完整运行目录。

## 实际实现
- 稀饭独立接入；电影/电视剧请求可查询稀饭、西瓜卡通、GiriGiri、樱花和配置化 HTML 适配器。
- 内容类型以条目分类、详情和明确版本标记为依据；动画电影与动画属性分开，保留类型、年份、季数及衍生版防误配校验。缺失证据不从简介、导航或集数猜。
- 有限预算补查详情；电影的 HD/4K/国语等完整版本映射为第1集的不同线路，不变成第4/1080集。
- 西瓜卡通动态播放器公开接口适配，仍限定 HTTPS、已知播放器域名和合法视频ID；拒绝或登录要求不绕过。
- 正式 MacCMS 20条（17启用、3原隔离）、80条候选及 AniCh 线路全部保留；候选接口修订不意味着自动启用。
- 新增可重复的完整来源验收工具，记录全部返回线路及失败状态，避免只检查前三条或遇到成功就终止。

## 已执行验证
- VPS隔离目录覆盖118个来源配置条目，四种真实作品、剧集第1/3集。西瓜卡通修复后专项重测通过。
- 共444条样本线路：171条服务器播放清单/必要密钥/首媒体片段验证通过，99条需客户端网络确认，174条未通过；没有用删除线路凑全绿。
- 真人剧《庆余年》与真人电影《流浪地球》经过真实标题、年份及类型匹配；Nivod/PPnix等独立来源返回的媒体进入实际验证。
- AniCh番剧样本第1/3集返回60/61条，全部验证，不设58条固定上限。
- 樱花补测《紫罗兰永恒花园剧场版》匹配成功，媒体需客户端验证；不冒充服务器可播。
- 西瓜动态接口回归先复现失败，再修复通过；兼顾拒绝响应、恶意域名、HTTP和非法ID。完整后端测试与精确HEAD CI结果保存在交付证据中。
- 四材料inventory沿用 engineering-goal-progress.md 的历史实读记录：total=4、read=4、skipped=0；不声称本轮重新读取历史四份原件。

## 发布与服务器验收标准
先正常合并main并推送，等待该精确SHA的Quality Gates成功后生成门禁凭据和双端产物、manifest。部署前备份代码、环境文件、数据库和上传目录；只变更已审核的版本文件，保存回滚清单。
在原allowlist上追加本轮通过的 age、xifan、xgcartoon、nivod、ppnix，保留原有四个provider及预缓存开关。服务器上线后检查服务、本机及公开API、真实三类作品和数据完整性；实际部署结果写入不可变发布证据，不在提交前声称已上线。

## 待确认与限制
- 来源条目不是独立站点数；未返回样本不意味着永久无资源，候选也不等于生产可用。
- 99条客户端待确认、174条服务器未通过均保留；该次片段验收不等于人工观看全片、所有作品/集数、长期可用或全设备首帧证明。
- 本版没有更改播放器布局和弹幕显示设置；上一版设备实测不冒充本版最终安装包的实测。
