# Zeluna v1.2.0

## 更新
- 播放来源面板补齐后端全部注册来源，明确显示未查询、未匹配、停用、候选未接入和旧兼容状态。
- 同一聚合器返回的独立线路全部保留，来源数与线路数分开统计。
- 对支持的正式 HTTPS MacCMS 增加“本机重查（本集）”。确认后，搜索、解析和媒体验证直接在设备执行，不静默回退 VPS，不自动切换正在播放的线路。
- 本机搜索严格核对作品、年份、类别和集数，支持番剧、电视剧和电影，含动画电影。
- 限时、有限并发，切集、重新搜索和账号/服务设置切换后不会被旧结果覆盖。

## 使用范围与说明
- 本机重查只影响此次本集操作，尚非持久逐源路由设置；普通发现仍走现有后端。
- 设备网络/VPN 的实际出口可能仍受限，不能保证避开 IP 墙。
- 登记条目并非全部可播；候选/停用/未接入来源不会因显示出来而被启用。
- 未更改已安装规则权限或用户数据，未新增韩国常驻服务。
- Android APK 延续项目已有内部兼容签名方式，非商店正式签名。
- 回归、部署、包哈希及精确 HEAD 的门禁凭据以本版本 release manifest/evidence 为准；真实设备首帧与持续播放不由协议单元测试代替。
