# Zeluna v1.1.13 弹幕显示设置与直接开关

## 背景与目标
用户要求真实打开作品验证弹弹play匹配，并将播放器中冗长的弹幕来源列表改为常用显示设置，在底栏提供不打开面板即可操作的开关。沿用现有剧场主题和 Android / Windows 共用的单行控制栏。

## 版本与范围
统一版本为 `1.1.13+67`，内部兼容签名 Release APK 与 Windows 完整 ZIP 同步交付。不部署服务端、不公开发布，不覆盖任何历史产物。底栏图标继续打开设置，旁边的独立开关直接控制弹幕；竖屏也有相同入口。

## 实现
- 播放器移除来源卡片和来源诊断请求；保留总数量、刷新和自己的弹幕管理，不取消后台自动匹配。
- 新增共享显示设置：透明度 20–100%、显示区域 1/4 / 半屏 / 3/4 / 全屏、字号 12–28、速度 0.5–2 倍，独立屏蔽滚动、顶部、底部。
- 播放器和个人设置页共用同一组件与账号隔离的持久化通道；恢复默认仅恢复显示参数，保留总开关与关键词屏蔽。
- 区域影响各类型的实际排布并裁剪边界；透明度包含描边阴影；速度同步影响移动和可见时间窗口。小范围仍可能在弹幕密集处出现重叠，没有承诺完整防碰撞排布。
- 独立开关保持 40 像素点击区域和可访问状态，不改变弹幕输入框同排位置。紧凑面板的类型选项保持一行。
