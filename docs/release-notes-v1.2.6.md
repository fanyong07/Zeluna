# v1.2.6 — Android 播放链路重构候选版

内部构建号77。此版本供真机复测，尚不能声称用户手机故障已解决。

## 更新

- 统一 Kazumi/XBPQ 的直链、嵌套页面与已授权脚本解析，保持来源请求头和权限限制。
- 快速选线不再等全部慢源；修复只检查前4个候选、遗漏后续可用线路的问题。
- 原生打开、取消、播放许可与续播集中管理，首帧必须有解码视频证据；不再把音频时间轴误报为画面。
- 经安全验证的备用 IP 错峰连接；保留证书、DNS和公网限制。
- 增加“播放来源 → 复制播放诊断”，只主动复制脱敏信息，不自动上传。

## 已验证与限制

1265项本地回归通过，28项按原条件跳过；API33隔离模拟器上，第一季第1集的 Bangumi/TMDB 两个入口完成画面解码及持续播放，实际选中 iKun。用户安卓真机、全部库存来源仍未验证，启动速度仍受线路和网络影响。

不需要后端部署，没有改动系统代理或账号配置。候选APK若使用历史兼容证书，仅用于原有安装的内部侧载/覆盖测试，不是商店正式签名。安装后若仍失败，请打开播放来源，点击“复制播放诊断”反馈。
