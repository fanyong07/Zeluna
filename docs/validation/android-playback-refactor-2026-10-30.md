# Android 播放重构验收记录（2026-10-30）

## 边界

本轮是核心解析/选择/连接/原生会话重构，不是对用户真机的成功证明。ADB 仅隔离 API33 模拟器，用户手机没有连接。不得用以下结果声称122个源全部可播，或承诺固定首帧时间。

## 修改前能失败的回归

- iframe 内有效视频被初始 HTML 解析漏掉。
- 已授权脚本嗅探未被 Kazumi 调用。
- 有音频时间进度但没有解码视频，也被记作首帧。
- quick 批量验证被静默候选拖住，另一条立即成功也无法交付。
- quick 硬截断前4个候选，第5个即使可用也不会尝试。

对应测试均先失败后通过。新增网络竞争、迟到 socket 清理、解析域名/凭据约束、取消、首帧代际、诊断脱敏及主动复制回归。

原生日志仍有 `lavf: Failed to create file cache.` 警告；此次未阻止解码和进度。不隐瞒该警告，也不据此认定每台手机的缓存配置无问题。

## 待真机闭环

新包在“播放来源 → 复制播放诊断”可主动导出应用版本、Android API/主ABI、阶段、首帧及安全的探测/传输错误分类。没有媒体 URL、账号、Cookie 或设备ID，不自动上传。用户手机仍需实际安装、打开第一季第1集，并在失败时提供此诊断。
