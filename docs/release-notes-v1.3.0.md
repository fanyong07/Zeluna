# Zeluna v1.3.0

Flutter version: `1.3.0+86`。本版合并三适配器播放修复与线路列表展示更新。

## 更新内容

- 播放线路以完整、扁平列表展示，不按 AniCh、Animeko、Kazumi 聚合器分组；隐藏聚合器前缀，保留 `hb-10` 等原始路线标签、稀饭动漫等真实站点名称。
- 延迟按速度使用绿色（≤500ms）、黄色（501–1500ms）、红色（>1500ms）；大小用蓝色、分辨率用紫色。未知数据为灰色，不填造数值；估算大小带“约”。
- 视频 URL 可查看完整内容和复制；操作 URL 不会切换当前播放线路。手机竖屏列表与完整线路面板共用同一组件，支持窄屏和较大字体。
- 完整发现与首播/验证预算分离；保留独立规则、渠道、请求头及失败候选，不把相同 CDN 主机名视为同一线路。超过解析预算的章节以待解析状态保留，不冒充媒体直链。
- 后台完整发现若仍在进行，客户端会在限定次数内续查快照，未完成时保持可重试。首帧后异步补充线路及当前媒体信息，不为更新信息重播或切换健康线路。
- 完善服务器与客户端之间的媒体元数据契约。MP4 使用整资源长度；HLS/DASH 清单文件长度不作为整集大小，源站质量标签不视作已测量像素尺寸。
- 修复三适配器发现、章节解析与客户端接力；增加 Android 原生视频输出/尺寸与首帧回归覆盖。
