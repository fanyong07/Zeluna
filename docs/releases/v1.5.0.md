# Zeluna v1.5.0

版本：`1.5.0+89`。本版合并保留 `v1.4.0` 的全部能力（Android 应用内更新与稳定性修复），并重点补齐影视剧/电影播放、社区订阅直连、HLS 自动去广告与私密媒体库支持；发布时 APK、Windows ZIP、Tag、Quality Gates 与 manifest 均绑定同一源码提交。

## 新增：影视剧、电影与社区订阅直连

- **MoonTV / LunaTV / LibreTV JSON 订阅解析**：客户端原生支持 `api_site` 与 `sources` 格式，自动归类番剧、电视剧、电影。
- **4 个已验证社区订阅一键接入**：在播放源管理页提供 `LunaTV-jin18`（已过滤 18+，覆盖影视/电影/番剧）、`Kazumi-Official`、`Animeko-MajoSissi`、`Animeko-Creamycake` 快捷订阅按钮。
- **私密媒体库直连**：支持挂载个人 Emby / Jellyfin（账号密码登录或 Token）、Alist 与 WebDAV（含匿名/局域网 HTTP、跨源公网 302 CDN 直连与连接测试），与在线源统一展示与播放。

## 改进：播放稳定性、去广告与起播速度

- **公开 HLS 仅清洗清单去广告**：Windows / Android 播放公开 HLS 流时仅在本地清洗 `.m3u8` 文本，全部 `.ts` 分片与密钥保持公网 HTTPS 直连由 `mpv` 原生拉流，既不经过 UI 隔离区代理视频字节（消除卡顿/假死），又能自动跳过采集站插播广告。
- **短切片电影防误剪**：客户端与服务端同步修正固定 2 秒短分片阈值在现代 2~4 秒 GOP 影视流上的误剪问题，无广告片源零误剪。
- **MacCMS 与 Kazumi/Animeko 解析加固**：自动过滤同条目的 HTML 共享页、提升探活并发槽位与超时预算、支持简繁标题归一、中英文季数等价、冒号副标题回退、同站 HTTPS 升级与同品牌 TLD 镜像跳转，以及单订阅组快速起播 12 槽位补满。
- **体验增强**：线路面板新增「有广告换线」一键降权、折叠未查询/未启用占位来源，并优化 Android 冷启动与 `mpv` 启动参数。

## 安装与更新

- **Android v1.4.0 用户**：可直接在 **我的 → 版本信息 → 应用更新** 中一键检查并下载安装 `v1.5.0`（保留原包名与签名，直接覆盖安装保留数据，勿先卸载）。
- **Android 首次安装 / 更早版本**：下载本页 `Zeluna-v1.5.0-Android.apk` 安装。
- **Windows**：下载 `Zeluna-v1.5.0-Windows.zip`，解压后运行 `Zeluna.exe`。

## 验证与发布依据

发布前本地验证通过全量 Flutter 静态分析（0 issues）、1554 项 Flutter 测试（28 项跳过）、1331 项服务端 Python 测试与 Ruff 检查、69 项 CI/发布工具单测以及仓库与供应链依赖门禁，并完成真实网络下的电视剧、电影、番剧全链路及 `manifestOnly` HLS 去广告端到端实测。最终 Git SHA、CI run、安装包大小与 SHA-256 以随附的 `Zeluna-v1.5.0-manifest.json` 为准。
