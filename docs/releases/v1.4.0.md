# Zeluna v1.4.0

版本：`1.4.0+88`。本版包含 Android 应用内更新和播放稳定性改进；发布时 APK、Windows ZIP、Tag、Quality Gates 与 manifest 均绑定同一源码提交。

## 新增：Android 应用内更新

- 入口：**我的 → 版本信息 → 应用更新**；杂项设置也可进入。
- 检查新版本，展示更新说明和安装包大小，支持下载进度、取消与失败重试。
- 下载完成后验证字节数、SHA-256、包名、版本、设备兼容性与当前签名，再交给 Android 系统确认安装。
- 支持安装来源权限引导，返回后再次点击安装；不自动安装、不卸载旧版、不清除业务数据。
- 已完成的下载可在重启后恢复并重新校验。可选启动检查默认关闭，每日最多检查一次，播放页面不显示更新提示。
- 默认读取现有 GitHub 正式 Release；匿名 API 限流时使用同仓库的备用发现路径。

## 改进：播放与长时间使用

- 降低播放进度更新引起的整页重建，减少播放器、选集与线路列表的重复布局。
- 修复原生截图参数的 64 位内存分配问题；首帧探测不再反复传输/编码完整截图。
- 给作品详情与弹幕时间线缓存设置容量边界，保留正常加载与播放行为。
- Android 网页解析任务串行执行，补齐取消、超时、清理与渲染进程退出后的隔离处理。

## 安装与更新

- **从 v1.3.1 或更早版本升级，仍需先手动下载安装 v1.4.0 APK 一次。** 之后即可在 App 内检查和下载后续版本。
- 保持现有 Android 包名与历史签名，以便覆盖安装并保留数据。不要先卸载旧版。
- Windows 提供完整运行目录 ZIP，解压后运行 `Zeluna.exe`；本版应用内安装更新仅面向 Android。
- 下载中断或系统结束进程后需要重新下载；已完成且未被系统清理的安装包可恢复。本版未加入断点续传或前台下载服务。

## 验证与发布依据

发布前本地回归包含 1511 项 Flutter 测试通过、28 项跳过，更新模块新增 56 项测试；原生更新策略 20 项测试、清单工具 39 项测试通过。已实际完成生产 APK 流式下载及哈希核对，并在 API 35/x86_64 隔离 Android 环境验证安装来源权限与系统更新确认界面。

本地测试不替代正式发布门禁；对应 Git SHA、CI run、最终包大小与哈希以本版随附的 manifest 为准。实体手机和厂商安装器差异未声称全部覆盖。
