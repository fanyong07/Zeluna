# Third-party notices

Zeluna is a Flutter client with a Python/FastAPI server. Exact transitive
versions and license metadata are resolved from the committed lockfiles and
must be regenerated by the dependency gate for each release.

Zeluna's own project code is licensed under Apache License 2.0 as recorded in
`LICENSE`. This project license does not replace or relicense third-party
components, assets, fonts, or services described below.

## Direct client dependencies

The client declares Flutter/Riverpod/router/network/parser/storage packages,
`media_kit` and its video libraries, `flutter_inappwebview`, file and secure
storage plugins, window/media controls, and the official Flutter web runtime.
The Windows WebView integration is a reviewed local override under
`third_party/flutter_inappwebview_windows`; it is not a private provider
implementation.

## Direct server dependencies

The server declares FastAPI/Uvicorn, Pydantic, SQLAlchemy/Alembic, HTTPX,
SQLite support, BeautifulSoup/lxml, protobuf, PyJWT, bcrypt, email-validator,
and APScheduler. Development tooling includes pytest, Ruff, and pip-audit.

## Bundled assets and external services

- Flutter Material/Cupertino assets and the Noto Sans SC/Noto Serif SC fonts
  remain subject to their upstream notices; the font license text shipped in
  `assets/fonts/OFL-NotoSerifSC.txt` is part of the artifact.
- Anime4K shader assets and the local source catalog are bundled project data;
  they contain no production tokens or fixed sampled media routes.
- Metadata providers and self-hosted playback endpoints are user-facing
  network integrations. Their names and terms must be reviewed before a
  release; no AniCh production API or VOD sample endpoint is a Zeluna provider.

## Verification

Run `tool/ci/dependency_gate.py` to verify lockfile advisories, licenses, and
the Flutter SBOM. Run `tool/ci/repository_gate.py` to reject secrets, private
artifacts, downloaded media, and other out-of-scope files. Generated reports
belong to the release artifact and must not be replaced with hand-edited lists.
